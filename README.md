# Genome K-mer Analysis

## Purpose

This project analyzes DNA sequence fragments by identifying overlapping k-mers and calculating:
1. The frequency of each k-mer
2. The frequency of characters that immediately follow each k-mer

## Requirements

- Python 3
- pytest

## Running the Script

```bash
python kmer_analysis.py input.txt output.txt 2
```

## Running Tests

```bash
pytest
```
